# Kitchen model assets

- Food models: Kenney Food Kit, https://kenney.nl/assets/food-kit (CC0; see Food-LICENSE.txt).
- Refrigerator: derived from Kenney Furniture Kit, https://kenney.nl/assets/furniture-kit (CC0; original OBJ and license in assets/kitchen-source).
- `fridge.glb` is rebuilt with `node scripts/build-kitchen-model.mjs`: Y-up, front +Z, bottom at Y=0, independent left door pivot, three added shelves. Original materials replaced using LiliumOS Clay tokens.
- Food assets are unmodified. Their original colors are asset artwork, not interface colors.
- These meshes describe appearance only. One food model represents one inventory lot, not one egg/package or a measured remaining volume.
