# Kitchen model assets

- Food models: Kenney Food Kit, https://kenney.nl/assets/food-kit (CC0; see Food-LICENSE.txt).
- Refrigerator: original LiliumOS geometry and procedural micro-normal textures, generated by `scripts/build-kitchen-model.mjs`. The retired Kenney Furniture Kit prototype is kept in `assets/kitchen-source` with its CC0 license; it is no longer used to generate the refrigerator.
- `fridge.glb` is rebuilt with `node scripts/build-kitchen-model.mjs`: Y-up, front +Z, independent `DoorPivot` and `FreezerDoorPivot`, transparent `CrisperLeft` and `CrisperRight`. Cold shelf tops: 0.56/0.93/1.3; freezer shelf top: 1.8525. Materials use Clay colors, enamel clearcoat, brushed metal, transparent plastic, rubber seals and embedded PNG normal maps. It can be imported into Blender using glTF import; no `.blend` project is generated.
- Food assets are unmodified. Their original colors are asset artwork, not interface colors.
- These meshes describe appearance only. One food model represents one inventory lot, not one egg/package or a measured remaining volume.
