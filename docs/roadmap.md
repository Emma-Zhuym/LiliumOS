## 当前优先级

### P0：规矩与同步安全

- 不再整体合并上游，只挑好的功能吸收；严格走 `.claude/CLAUDE.md` / `AGENTS.md` 的审批闸门：先只读调研、汇报，阿萌选完才建验收分支。没有固定节奏。
- 吸收上游功能后跑 `bash scripts/check-em-patches.sh`（当前 277 项）和 `pnpm vitest run`；动了后端再跑 `node --test server/agent-backend/*.test.mjs`。
- EM App 数据备份必须持续覆盖 Finance（含周期规则）、Health、Shopping、Map、Moments、Smart Home。
- 剧情剧场默认独立故事线与独立记忆；只有用户显式开启才镜像进角色记忆。

### P1：烛下（聊天里的深谈）

- 阿萌 2026-10-22 定开工、定名「烛下」。实施契约 `docs/spec-deep-talk.md`：阶段一（手机端闭环）已做、等验收（见上表）；阶段二 mini 到点来叫和 TA 主动约，阶段三动态蜡烛和情侣空间书架。

### P1：结构梳理（一样东西一个家）

- 阿萌 2026-10-22：功能越加越杂，同一类东西散在好几处还不通气（他的一天分在 10 个地方；健康、记账上游和 EM 各一套；设置里感知和工具混着）。
  不再 merge 上游，可以按自己的想法重排，但**不一次推倒**：一次只给一样东西搬家，每一步一晚上能看到效果。
- 原则：**每类东西只有一个家，别的地方只是开在它上面的窗**。地图（现在散在哪 → 以后的家）是在聊天里画的，要点记在这里：
  1. **设置按「给角色什么」分** ✅ 2026-10-22：角色能感知（天气、新闻；运动 10-22 已删）/ 角色能用的工具（日记同步、小红书、MCP、网页抓取）/ 设备与网络
  2. **身体和钱只留 EM 那套**（阿萌 2026-10-22 定）：
     - 上游的「生活记录」（经期 / 药盒 / 锻炼，在角色设定里）和上游旧账本**直接删**，阿萌从来没开过，不用搬数据
     - 角色代记（`utils/emScribe.ts`）只留**症状**和**经期**；开销、锻炼、睡眠不记（Apple Health 已经自动同步，记了重复；开销她自己记）
     - 角色**照样能看**健康摘要、记账流水、冰箱这些（只读不碍事），契机池和心跳拿账本当话头也保留
     - 以后可以加：健康 App 里的吃药 / 维生素打卡（她想把维生素 B 吃回来），角色可以顺口提醒
  3. **我的安排以日历为家**（阿萌 2026-10-22 定）：
     - **日程 App 退休**：里面的待办和任务（含上游自带的「监工」）她后来几乎不用，跟着删

     - **角色看了纪念日写的感想**（`Anniversary.aiThought`）先停在原地，等情侣空间做好，作为 TA 贴在便签墙上的一张便签
     - 待定：日历现在是 indigo（事件）+ orange（提醒）+ 中性灰（约定），纪念日用什么颜色要算进每屏彩色预算，出样稿时再定
  4. **机房拆开，变成「窗台」**（阿萌 2026-10-23 定；2026-10-27 先做了搬家：脾气 → 神经链接、机器 → 设置 → Mac mini ✅，窗台的小卡 / 时间线 / 热力条还没做）：

- **聊天**：交给 Mac mini 即时回复（杀后台也能收）、通讯录、Token / 召回记忆面板、写 Notion 快捷键、Online / Busy / Offline 状态、角色代记、文字语音条、聊天记录搜索、MCP 调用记录、独立聊天设置与私人备注、角色独立 API、生图 API 与立绘参考。
- **角色的生活（Mac mini 后端）**：心跳（先读你的消息、开口抽签、连发没回会收手、生活小事、工作往来、社交与约定、逛小红书、刷朋友圈）、月度总结进心跳、约定进聊天和日历、起居注、工作 App、朋友圈、日常节律。
- **现实接入**：Apple Health（经 HA）、Apple 日历 / 提醒、位置感知、SimpleFIN 记账（预扣款自动配对、手动不计入）、Home Assistant 共栖舱、小红书（mini 常驻）、Open-Meteo 天气、中文热榜。
- **App**：Finance、Health、投喂站、地图×日程、日历、共栖舱、朋友圈、查手机增强、照片收藏、Intiface、七夕等特别时光。
- **工程**：EM 哨兵 + `check-em-patches.sh`、提示词外置 `emPromptAddons.ts`、完整备份覆盖 EM 数据、换皮「F」设计系统。
