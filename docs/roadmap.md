## 已完成

### 2026-08-31（渐进式账目整理验收分支）

- SimpleFIN 新交易从单一强制复核升级为兼容旧备份的渐进状态：未识别、暂时跳过、一级已确认、已细分和自动分类；只选一级分类即可完成，不再强制选择子分类。
- 存钱罐角标只统计最近 7 天仍未识别的同步交易；显式“先放着”和旧于 7 天的账目不继续制造桌面待办压力，原始流水仍完整保留。
- Amazon 模糊交易提供金额/日期固定提示和“我记得是什么 / 去 Amazon 查 / 先放着”轻操作；Amazon、Target、Walmart 等多品类商户不参与自动学习。
- 同一稳定商户连续三次被人工归入同一分类后，后续交易在本地以 98% 置信度自动分类；规则只读取本地账本，不上传消费内容。
- 待后续决策：Amazon 邮件/订单匹配需要独立邮箱授权；角色替用户批量写分类需要单独定义写账确认边界，本轮均未接入。

### 2026-08-27

- 单角色私聊页新增聊天记录搜索：入口与回复触发并列放在聊天顶栏，只读取当前角色的完整私聊历史；可按关键词与日期/语音/链接/卡片筛选，普通文字保留在默认“全部”结果中，不增加低价值的文字和发送方筛选。点击日期会在当前搜索页原地展开月历，选定后收起并显示具体月/日；有聊天的日期亮起、无聊天的日期变暗且不可选，结果可跳回原消息，图片继续统一从角色相册查看。
