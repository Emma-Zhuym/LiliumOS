# 七夕「星月梦境童话」契约

> 状态：已合入 LiliumOS。活动内部为上游原作的全屏沉浸叙事，不作为普通 Clay App 页面骨架复用。

## 入口与时效

- 北京时间 `2026-08-19` 首次启动会出现一次邀请弹窗；关闭或进入后均不再重复打扰。
- 「特别时光」里的七夕卡片永久保留，不受当天日期限制。
- 已完成的角色可以选择重看上一次或开始新的一次；重看不调用模型，也不重复写入私聊。

## 生成与 API

- 新旅程在生成前明确确认，共调用 **4 次模型 API**：前三次分段生成七个地点与鹊桥材料，第四次生成重逢、约定和返回私聊的话。
- 四次请求均为流式、零自动重试；失败时由用户决定重试当前部分或退出，避免重复消耗额度。
- API 必须通过 `resolveCharacterApiConfig` 解析所选角色的聊天预设；未绑定或预设失效时才回退主 API。

## 记忆与聊天连续性

- 活动会读取最近私聊，并在角色启用记忆宫殿时执行七夕专用召回；专用格式化上限为 20 条，不改变普通聊天默认值。
- 完成后写入一张 `qixi_event_card` 和一条角色返回消息；以 `qixiRunId` 做幂等检查。
- 完整七个场景、鹊桥节点、重逢、祝福与约定会被格式化进未来聊天上下文。
- 可重放快照保存在角色 `specialMomentRecords.qixi_2026_dual_layer_v7`；稳定存储键不随内部快照版本改名，避免旧记录失联。

## 兼容与降级

- 立绘优先使用见面模式表情，其次 Q 版形象，最后回退头像首字；调整后的立绘位置可同步回见面模式。
- BGM 可静音，音频镜像优先使用支持 byte-range 的 GitHub Raw。
- 流式读取遇到 `[DONE]` 或 `finish_reason` 会主动收口，兼容生成完仍不关闭连接的代理。
- 词云材料不足时提供继续出口，不让旧存档或非标准模型响应把用户卡死。

## 关键文件

- `components/events/qixi/`：活动界面、交互与 BGM
- `utils/qixiMemoryBundle.ts`：七个地点与鹊桥材料
- `utils/qixiReunion.ts`：最终重逢与约定
- `utils/qixiChatCard.ts`：聊天写回与上下文格式化
- `utils/qixiLaunchPopup.ts`：北京时间入口闸门
- `components/ValentineEvent.tsx`：特别时光入口、角色 API 解析和完成存档
