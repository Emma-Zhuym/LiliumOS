## 怎么写

每完成一件事（合进 `main` 或者上线了），在对应月份最上面加一条：

```markdown
### 2026-09-26 · 一句话标题
**操作**：Claude（小帕） · PR #5 · `6646327`

- 改了什么（用人话，一条一件事）
- 用户需要做的事 / 还没验收的地方（有就写）
```

- **操作者**：`Claude（小帕）`、`Codex（Elias）`、`阿萌`；几个人一起做的就都写上。
- 一天做了好几件不相干的事就分几条；同一件事拆成十几个提交也只写一条。
- 只写结果和边界，不写过程；实现细节留在提交信息和对应的 `docs/` 规格里。
- 上游 SullyOS 同步也记一条，写清楚同步到哪、要了哪些、没要哪些。
