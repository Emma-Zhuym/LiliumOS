# 聊天设置独立页面提案

状态：2026-09-12 Emma 已批准实施；顶部身份卡收紧为 48px 头像与两行姓名信息，移除神经链接说明文字。

## 入口与页面

- Chat 右上角搜索图标改为三个点，进入独立「聊天设置」页面。
- 固定顶部返回与标题，下面为可滚动分组列表，沿用 APP_CONVENTIONS.md 和 clayTokens 的暖白 Clay 样式。
- 顶部角色身份卡展示头像、备注（若有）与原名。Chat 头像和身份卡头像均直达当前角色的「神经链接 → 设定」。返回聊天保留原位置。
- 身份卡下方为设置备注，再下方独立放置查找聊天记录入口，复用现有搜索功能。
- 参考图仅借鉴布局，不额外新增置顶、免打扰、群聊或投诉功能。

## 原设置内容归并

- 聊天方式：输入与回复、主动与定时消息、语言与语音。
- 记忆与能力：上下文与记忆（智能语境、原文范围、归档设置），扩展能力（原有小红书、HTML、发照片风格及迁入的麦当劳）。
- 聊天外观：背景与聊天装扮、白框自定义、思考与系统消息。背景入口去重；原系统日志开关归入最后一项。
- 聊天记录：管理与清理记录，保留原有清理范围与确认行为。
- 第一层只放分组入口，细项进入对应设置视图，避免把全部开关摊在一个长页面。

## 私人备注

- 为角色按稳定 ID 独立保存 UI 备注，不修改角色原名，不把备注写入角色设定。
- 联系人列表和聊天标题优先显示备注；清空备注恢复原名。
- 设置身份卡同时显示备注和原名，避免混淆。
- AI 的人设、消息历史、提示词继续使用原有名字与内容，备注不参与生成请求。
- 实施时单次检查备注显示与 AI 请求组装的边界；不进行重复或防御性测试。

## 已批准的收藏规则继续生效

Chat 所有消息使用一个收藏按钮、同一条消息一个收藏状态。收藏夹保留文字排版与换行、图片、语音条（点转文字再展开，美化条不调用语音 API）、HTML 卡片。分类仅用于查找；搜索匹配语音文字后仍显示语音条。
