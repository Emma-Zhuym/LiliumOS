设置子页重做样稿

把上游一块一块的大彩色卡片，换成跟设置首页一样的分组列表。点左边的四行进去看，开关、分段、小圆片都能点。

几种零件，所有子页通用

  • 开关行：打开后相关的选项才在同一组里冒出来，关着时只有一行。
  • 填写行：小标签在上，平底输入框在下；Token 一律显示成圆点。
  • 状态卡：连接类的页面顶上一张淡蓝卡，写连没连上、什么时候测过，右下角「测试连接」。
  • 分段：二选一（自动定位 / 固定城市、本地 / 云端）用灰底白块滑动。
  • 小圆片：多选（新闻平台），选中是实心蓝。
  • 蓝字行：一次性的动作（测试一下、导出、添加），不再画成大按钮。
  • 灰色小字：说明写在每组下面，不再塞进卡片里。
  • 高级 / 危险：很少碰的收进「高级」；会删东西的单独一组放最底下，红字。

顺便去掉的

  • 飞书日记、麦当劳、瑞幸、运动感知（roadmap 里已经定了删）。
  • 每块功能各一种颜色的底。整页只剩设置的蓝，绿点和红字只表示状态。
  • emoji 和渐变按钮。
