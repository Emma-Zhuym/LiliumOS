# 世界书条目：难过时来哄我

新模型遇到难过的事，默认会复述、给空建议、反问用户想听什么。这多半来自各家的训练，我们改不了权重，只能在提示词里尽量往回拉。

规则已经进了私聊提示词（`utils/emPromptAddons.ts` 的 `emComfortSection`）。规则告诉模型「别怎样」「要怎样」，压不住习惯时，**示范比规则管用**，所以这份条目主要是示范对话。示范要写成那个角色自己的话才有用，所以放世界书，一个角色一份。

## 怎么加

新建一条世界书，挂到想要的角色上：

| 选项 | 填什么 | 为什么 |
|---|---|---|
| 启用关键词触发 | 不勾选（始终生效） | 难过的时候不一定会说到某个关键词 |
| 注入位置 | 聊天记录指定深度 | 离模型开口最近的位置，比放在设定区管用 |
| 消息深度 | 1 | 插在她最新一条消息前面。0 会排在最后，部分中转不接受最后一条是系统消息 |
| 消息角色 | System | |

下面「条目内容」整段复制进去，再把示范改成这个角色的口气。**一定要改**：不改的话，每个角色都会说得差不多，也可能直接照抄。

示范里的情节也要换成你们之间真有的事。角色跟你不在一个城市，就别让 TA 说「在路上了」。

## 条目内容

```text
[她真的难过时，你就是这样回她的。这是你以前的样子，不是台词，别照抄，每次都用当下的事。]

她：论文又被拒了 我是不是真的不行
你：
哪个审稿人
名字给我 我去他家门口放鞭炮
……算了 我不知道他家在哪
你吃饭没有 没吃我现在给你点上次那家粥 不接受反驳

她：没事 你忙吧
你：
不忙
忙也不听
你不用说话 我发语音给你 你就听我洗碗
要是摔了一个你得赔我一句话

她：……
你：
去年你哭完是吃了三个冰淇淋才好的
我买了四个
先别问为什么是四个

她：别哄了 没用
你：
嗯 没用
我再待会儿
刚才那个笑话确实烂 我换一个更烂的

她没说要什么，你也不等她说。你先做点什么；她不接，你换一样再来。
写完看一眼第一句：要是在说她刚说过的事，就删掉，从下一句开始。
```

## 改的时候照这几条

- **第一句就是反应或动作。** 不从她刚说的事开头。
- **每段都有一件只有这个角色会做的事。** 换成别的角色还说得通，就再改。
- **留一段她推开你的示范。** 模型最容易在这里退回去，上面第四段就是干这个的。
- **别写「错误示范」。** 把坏句子写进去，模型反而容易学到。

## 跟「活人感世界书 3.0」（白咪饭）一起用

这个合集没有专门讲怎么哄人的模块，它管的是平时的活人感。这份条目补的就是这块。

| 那边的条目 | 建议 | 原因 |
|---|---|---|
| 反复述反问与对话美学 | **挂上** | 专门治复述，还带开口前的自检，跟这份互补 |
| 全景情绪光谱 | 可以挂 | 情绪不秒切，难过之后还留着余波 |
| 活人热梗 + 用语 | 挂的话不用改 | 自带一条：她难过时立刻关掉玩梗 |
| 去油腻与管教 | 挂之前改一处 | 「情绪投射」那段要求克制、拒绝用力过猛，会把软话和肉麻话也压掉，加一句「她真的难过时这段不适用」 |
| 小克增浓度 | 挂之前改一处 | 允许角色疲惫时反过来找她要安慰，加一句「她正难过时不向她要」 |
| 独立人格 | 可以挂，看效果 | 要求角色不以她为中心，主要管平时；如果哄到一半开始讲自己的边界，就先摘掉 |

**反复述那份挂之前也要改两处：**

1. 「留白与选择性忽略」那段加一句「她难过时不留白、不忽略」，否则模型可能把她的话晾在一边。
2. 「强制引用」那段写的是别的软件的 JSON 格式（`quote_reply`），不是糯米机的。删掉这一段，糯米机自己的提示词已经教了引用，留着可能把 JSON 原样发出来。

**别整套全挂。** 全面版加精简版约 17 万字，每轮都要带上，又贵又互相打架。先挂反复述那份和这份，确实缺什么再加。

这个合集的原文没有抄进这份文档，这个仓库是公开的。

## 还是不行的话

- 这份条目和提示词都**没有用真模型测过**。不同模型效果可能差很多。
- 改了还复述，就把示范再加两段，写成最像你们平时的样子；示范越像真实聊天记录，越容易跟。
- 从聊天记录里挑一段以前哄得好的原话当示范，通常比新写的好。
- 同一个角色可以换 API 试：哪家听示范的话，记下来，难过时用那家。
