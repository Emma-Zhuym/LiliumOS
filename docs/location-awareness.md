# 位置感知聊天

## 产品边界

LiliumOS 的位置感知使用本机地理围栏。真实地图来自 OpenStreetMap，不需要 Google Maps Key，也不做地址反查或地点自动补全。

- `家`、`学校`各保留一个范围；再次保存会替换旧范围。
- `超市`可以保存多个，并允许自定义名称。
- 未命中任何范围时，状态统一为`在外面`。
- 围栏中心经纬度只保存在当前浏览器的 `localStorage`，不进入角色提示词、API 日志、Engram 或完整备份。浏览真实地图时，OpenStreetMap 瓦片服务器仍会收到普通地图瓦片请求。
- 角色只有主动调用本地位置工具时，才收到粗略语义和更新时间；工具结果不会包含经纬度。

## 使用流程

1. 打开`地图 → 我的位置`，点右上角加号。
2. 选择家、学校或超市，填写名称并设置 50–1000 米半径。
3. 在真实地图上点选中心；也可以粘贴包含坐标的完整 Google Maps / Apple Maps 链接，或输入`纬度, 经度`。人在现场时可用`把地图移到当前位置`。
4. 点`保存这个范围`。家和学校会替换同类旧范围，超市可以保存多个。
5. 打开某个角色世界的`编辑世界 → 现实地点联动`，把现实地点关联到该世界里的虚拟地点。
6. 可以随时关闭`允许角色感知`；关闭后工具不可用。

完整地图链接必须直接包含经纬度。`maps.app.goo.gl` 一类短链接需要联网跳转才能展开，当前不会自动解析；可以改用地图点选或粘贴坐标。

进入位置页会尝试刷新一次。普通聊天不会自动读取或注入位置；角色在对话自然需要时可调用`get_user_coarse_location`，这时浏览器才尝试前台定位。定位失败会使用带更新时间的本机缓存，超过 6 小时的缓存视为未知。

角色虚拟地图使用`现实 zoneId → 该世界 regionId`的语义绑定。每个角色世界可以有不同对应关系，地图会同时显示青绿色的“你”和紫色的角色标记；同处一个区域时标记会错开。

## PWA 与云端限制

网页和 PWA 无法在 iPhone 上持续后台读取 GPS。当前版本只覆盖位置页和本地聊天工具调用时的前台定位；关闭感知后不会继续读取。

Instant Chat、Instant Push 与未来主动心跳运行在云端，当前不能调用手机上的本地 GPS 工具。后续若要让角色在后台醒来后感知位置，应由 iOS 快捷指令的到达/离开自动化向受控后端发送`home / school / supermarket / outside`语义事件，而不是上传持续轨迹。该后端链路尚未实现。

实现入口：`utils/locationService.ts`、`utils/locationChatTool.ts`、`components/RealLocationPicker.tsx`、`apps/MapApp.tsx` 与 `hooks/useChatAI.ts`。
